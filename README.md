# 🚀 Portfólio Hub — Ciência da Computação

Bem-vindo ao repositório do meu portfólio profissional e acadêmico. Este projeto foi desenvolvido durante a disciplina de **Bootcamp** no 1º período de Ciência da Computação, com foco em centralizar minha evolução nas áreas de **Desenvolvimento Full Stack** e **Cibersegurança**.

O design foi construído seguindo uma estética minimalista, premium e de alto contraste (cinemática), focada em performance e clareza visual.

🌍 **Acesse o portfólio online:** [cauajuniio.github.io/portifolio-hub/](https://cauajuniio.github.io/portifolio-hub/)

---

## 🛠️ Tecnologias e Recursos Utilizados

* **Front-end:** HTML5 semântico, CSS3 (Custom Properties, Grid, Flexbox)
* **Animações & Dinâmica:** JavaScript Vanilla (`IntersectionObserver` para revelação de elementos e efeitos de scroll)
* **Hospedagem & Controle de Versão:** Git, GitHub e GitHub Pages

---

## 📂 Destaques do Portfólio

* **SmartPark IoT (Conceitual/Em Desenvolvimento):** Sistema ponta a ponta de gerenciamento de estacionamentos usando sensores de presença em tempo real, backend em nuvem e reserva de vagas via app para evitar concorrência.
* **PyShield (Conceitual):** Scanner automatizado de vulnerabilidades de rede local em Python para detecção de portas abertas e falhas críticas de configuração.
